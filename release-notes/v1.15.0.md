# RigOne 1.15.0 — Plugins and a Discord trigger

*Released on 2026-11-07.*

Plugins arrive with a store in Settings, a Discord trigger can start a workflow, and switching a chat to Auto keeps what you already said.

- Settings → Plugins works like a store, with Installed and Store tabs, search, and Install or Uninstall on every plugin. Opening a plugin shows its own page with author, status, what it needs, a description and screenshots. Store details come from rig-one.io, and RigOne keeps the last copy for offline use and says when it could not reach the store.
- Lab is now a plugin you can turn off in Settings → Plugins. With Lab off, its screen, sidebar button and search entry are gone, and Auto no longer offers evaluations. The change takes effect after a restart.
- A trigger can watch a Discord channel and start the chosen workflow when someone mentions the bot; the message becomes the task. The trigger editor asks for the channel ID and the environment variable that holds the bot token, and can test the connection. Agents in the run can reply in Discord, and the bot never starts a run from its own messages. Discord is not installed until you install it in Settings → Plugins.
- Turning Auto on in a live conversation keeps the plan and the message. The Auto Lead gets the earlier messages, and if the conversation still cannot be restored, the goal starts from your message with a short note instead of being refused.
- Remote access opens again after a restart when the phone's message history holds an answer it cannot match to a question, so conversations reach the phone and their history is kept.
- Auto no longer stops a goal for a design review when the work only adds, changes or deletes test files, and planning no longer asks for a design task in that case.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
