# RigOne 1.2.2 — agents reach every Connection

*Released on 2026-10-08.*

We checked whether agents can actually use their Connections, with real Claude and Codex under
RigOne's file boundary:
- in Auto and in ordinary workflows;
- for agents that change files and for testers that only read;
- for the Lead.

The RigOne bridge, the Playwright browser (a tester opening a real page, with or without a window)
and Figma through its sign-in now work everywhere. This release fixes what that check found.

- **A tester that uses the browser no longer fails its step.** Playwright saved its page snapshots
  inside the step's copy. RigOne counted them as changes outside the step's declared scope and
  marked the step failed. Those files now go to a private folder of the step.
- **A Codex Lead can use the browser.** Its Playwright calls were refused with "MCP tool call
  requires approval". A Codex Lead now approves its Connections the same way a Codex step does. The
  RigOne bridge still allows only the actions the Lead may take.
- **Codex history shows what you saw live.** After a Codex step finished, its history lost every
  command, edit, search and Connection call, and the note that a Connection did not start. Both now
  stay.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
