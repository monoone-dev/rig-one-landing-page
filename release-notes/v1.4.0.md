# RigOne 1.4.0 — Needs you, design review and steadier Auto

*Released on 2026-10-12.*

- **Needs you.** Every decision that waits for you sits in one list: the Lead's questions,
  approvals, exclusions and design reviews. Each one says what it is about and what happens after
  each answer. Answers are numbered, exclusions of the same kind can be decided together, and
  the list keeps what you already decided.
- **Design review.** When an Auto result changes screens, RigOne shows you the tester's
  screenshots before the result is recorded. Accept them, or click a spot on a screenshot, write
  what should change, and send the comments; the Lead turns each one into the next repair. A task
  that changes the interface needs a check made on screen, and a new screen in a project without
  mockups or design notes starts with a design task. You can turn the review off in Settings →
  Auto.
- **Notifications.** When RigOne is not in front, macOS tells you that a decision is waiting,
  that a goal finished or stopped, or that the Lead stopped. The RigOne icon in the Dock shows how
  many decisions are waiting. Clicking a notification opens Needs you.
- **Auto goals per tab.** A run stays in the tab that started it, and Stop in one tab no longer
  stops a run in another. Two tabs can now each run their own Auto goal in the same folder; their
  workflows take turns in that folder.
- **Saved goals in one list.** Resume a saved goal from one list in the header of the
  conversation, instead of a button beside each old goal. Very short entries are tucked away.
- **Auto keeps going after a usage limit and a sleeping Mac.** A step waiting for the provider's
  limit to reset now resumes at the reset time even when the Mac slept in between.
- **Steadier Auto.** A resumed Codex step keeps its model. A step whose agent left a command
  running after its answer keeps its result. Messages queued for a step arrive together in its
  next turn. Chained tasks that edit the same files no longer clash when their result is
  recorded. Turns that Claude starts on its own no longer count as the Lead's turns. A paused goal
  still tells the Lead when a workflow finishes.
- **Clearer Lead tools.** Goal status no longer floods the Lead with every finished part, and
  shows parts that can never start on their own. A plan check says when tasks could run together
  but are set to run one after another, and read-only reviews no longer wait for each other. A
  Lead command can be the first step of a task, a message from you can be a source of a part, a
  changed source can be pinned again, and the Lead can report a problem on a workflow that already
  failed.
- **Boards.** In a task started as Auto, progress and the final status now reach the board after
  a question is answered there.
- **Fewer false alarms.** Pulling new commits of the checked-out branch is no longer reported as
  Lead work outside a workflow, and the stream no longer repeats the first sentence of an opened
  answer.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
