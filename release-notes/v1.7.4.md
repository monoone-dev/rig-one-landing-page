# RigOne 1.7.4 — YOLO mode beside the model settings

*Released on 2026-10-20.*

Auto uses the normal connections and sign-in of Claude Code, Codex and OpenCode.

- Added a YOLO mode checkbox beside model settings, using the agent app's real permission mode.
- Fixed Auto stopping before the first model response with a connection or workspace routing error.
- Restored full access for Auto agents, checks and commands, while keeping work in separate execution copies.
- Restored the Lead's configured connections and available personal tools.
- Kept workflow results, usage limits and process cancellation in RigOne.
- Improved automatic project setup when analysis sources or research responses are unusable.

Auto with full access has the same access to your computer as an agent you run yourself in a terminal.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
