# RigOne 1.8.0 — Project setup that saves its work and resumes

*Released on 2026-10-20.*

Project setup now saves its work and can resume after an interruption.

- Simplified setup to project analysis followed by generation, without a required web research stage.
- Saved completed analysis and proposed roles, skills and context, including proposals that need correction.
- Added resume and repair actions; repairing a role preserves the other proposed items.
- Fixed design system detection through assigned skills and connected unambiguous project design sources automatically.
- Added project setup and native role export for OpenCode alongside Claude Code and Codex.
- Added a shorter setup time limit and cancellation when an agent stops reporting progress.
- Fixed duplicated approval cards after replay and removed stale cards when their question is no longer waiting.
- Added visible feedback while sending an answer from the composer approval card.
- Synchronized phone approvals with the exact desktop question, so accepted cards stop blocking the desktop.
- Kept a valid phone unlock when returning to the PWA or reconnecting; action confirmations and unlock expiry remain enforced.
- Made notification setup visible directly on the phone home screen.
- Added a dedicated home section for design reviews, with screenshots, acceptance and feedback from the phone.
- Fixed mobile access to review screenshots saved in the goal and workflow evidence folders.
- Allowed additional Auto repair attempts automatically in YOLO mode.
- Fixed saving and reviewing earlier Auto results after the project's main branch advances independently.
- Kept a valid setup applicable when another, unused agent app becomes available.
- Applied the chosen full access to review processes so they can run checks and save their evidence.
- Waited for stderr before publishing an agent's terminal failure, preserving the actual cause under load.
- Used a conventional branch name for private Auto copies while keeping older saved copies readable.
- Distinguished a failed check command from reported test failures.
- Kept conversation permissions consistent between the delivery receipt, saved history and a host restart.
- Kept Auto restarts compact as saved check history grows, with complete earlier file versions available on demand.
- Updated TLS certificate verification to reject distrusted intermediate keys (RUSTSEC-2026-0382).

- Updated the bundled TLS root certificates to remove a distrusted certificate authority (RUSTSEC-2026-0383).

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
