# RigOne 1.8.1 — A smoother window during long work

*Released on 2026-10-21.*

This update improves responsiveness during long conversations, design reviews and Auto work.

- Load saved file changes only when opened, instead of including complete file versions in every status update.
- Keep long conversation views bounded while preserving access to earlier messages.
- Load review thumbnails as they enter view and limit concurrent image reads.
- Keep connection initialization and skill discovery details out of the conversation.
- Show when a rejected result has a correction in progress, with clearer current-step and activity details.
- Start manual workflows in their own conversation cards, with Stop and Continue addressed to the selected run.
- Create private working branches explicitly from their pinned commit, without requiring a matching branch in the project folder.
- Start new Auto goals from the repository's detected default branch unless an explicit starting point is selected; preserve saved bases when resuming.
- Add a compact branch indicator with details for project folders, Lead copies and active working copies.
- Separate proposed project setup from applied configuration, with visible role counts and a fixed action footer.
- Add a single action to repair supported model replacements in managed roles without running inference.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
