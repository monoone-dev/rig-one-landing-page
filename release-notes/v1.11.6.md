# RigOne 1.11.6 — Auto keeps the effort you set for an agent

*Released on 2026-10-27.*

Auto keeps the effort you set for an agent, and run history shows what really ran.

- When the Lead does not name an effort for a step, the step starts from its role's saved effort instead of a level picked from the task's size.
- The Auto conversation's own effort no longer caps the steps it plans. It applies to the Lead only.
- Hard, risky or cross-cutting steps are no longer planned below their role's effort unless you ask for less.
- Run history records Claude steps by their full model name, and Codex steps by the effort Codex actually used for the turn.
- RigOne starts git directly instead of through wrapper launchers, so each git call starts one process instead of three. Agents still use your own PATH.
- Everything from 1.11.5 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
