# RigOne 1.3.0 — Boards: shared task boards, encrypted on your Mac

*Released on 2026-10-11.*

- **Boards.** A new Boards section (⌘9) holds shared boards with tasks, comments and members.
  It works without choosing a folder, and your local work stays on this computer: Boards is the
  only part of RigOne that needs an account.
- **Sign in with a MonoOne account.** Create an account or sign in from Boards or from Settings.
  An existing IndexOne account signs in with the same email and password. The password is
  checked with OPAQUE, so the server never learns it.
- **Encrypted before it leaves your Mac.** Tasks, comments and activity are encrypted and signed
  on your Mac; the server only relays ciphertext. Board keys are kept in the macOS Keychain.
- **Invite people and approve their devices.** Invite members by email as Editor or Viewer.
  Before a new member or device receives a board key, both sides compare the same fingerprint.
  The server refuses changes from a Viewer.
- **Works offline.** Changes made without a connection wait in a queue and are sent when the
  connection returns.
- **Run a task from its board.** Start a task as a saved workflow or as an Auto goal, in a
  folder you choose on this Mac. One computer claims the task: a second Start elsewhere is
  refused with the name of the device that runs it. Progress and the final status appear on the
  board for every member.
- **Answer an agent from the board.** A question from the agent appears in the task and as a
  notification. A member who can edit the board answers it there; RigOne checks the author's
  current role and passes the answer to the run exactly once.

**Known issue.** In a task started as Auto, after a question is answered on the board, the
progress that follows and the final status may not appear on the board. Tasks started as a
workflow are not affected.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
