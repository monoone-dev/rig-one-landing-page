# RigOne 1.6.7 — Remote you can use every day, and a calmer window

*Released on 2026-10-16.*

## Remote access from your iPhone

- **Messages go straight through.** Sending a message to a thread or typing your own answer no
  longer asks for Face ID; the normal unlock is enough. Messages reach any Lead, not only one
  open in a window on the Mac.
- **One tap to unlock.** The Unlock button starts Face ID right away, without a second dialog.
- **The phone keeps its session.** A lost message, a relay hiccup, the Mac renewing its sign-in or
  a second tab no longer end the session or ask for Face ID again. "Reconnecting to your Mac…"
  shows for a short break before "Your Mac is offline".
- **Loading states everywhere,** and the app fits the iPhone screen without zooming.
- **Readable diagnostics.** "Show diagnostics" groups events by Pairing, Connection, Unlock,
  Requests and Errors, collapses repeats, and still copies the full log.
- **Unpairing from the phone works,** and a phone removed on the Mac says so instead of waiting.
- **Pairing is sturdier.** A stalled pairing on the Mac ends or can be cancelled, a fourth Face ID
  try is no longer refused, and a short network break no longer uses up the code.
- **Home stays live.** Opening a task, run or service no longer freezes Needs you, and project
  lists no longer rewind after a reload.

## The window

- **Auto lets you pick Codex,** and keeps the model and effort you choose.
- **A finished Auto task no longer looks live** next to a run the Lead started.
- **A new board, list and task view in Boards.**
- **The spending warning is optional** and off by default.
- **A second redesign pass** with clearer focus, contrast and wording.

After updating, remove old phones in Settings → Remote access and pair your iPhone again.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
