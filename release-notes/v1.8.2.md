# RigOne 1.8.2 — Steadier manual runs and tighter Auto access

*Released on 2026-10-21.*

This update fixes manual runs, tightens access in Auto, simplifies project setup and improves recovery.

- Manual Run works again for workflows whose steps use the project folder.
- Stop and messages reach the run you selected, and runs show readable names instead of identifiers.
- Your earlier messages keep the "You" label.
- Review roles stay read-only, and unticking YOLO really keeps Auto in its own copy.
- Access and protection texts describe exactly what each setting allows.
- Project setup now generates and applies in one step, with Undo, and gives every agent all skills and web access.
- Model repair works without Codex and keeps working when an older setup preview names an unavailable model.
- Recognize saved working copies after a macOS restart without replaying results that were already recorded.
- Return unread check results to the Lead instead of asking to repair tests that never failed, and reject unsupported check proof syntax before work starts.
- Validate screenshot dimensions before showing review images.
- Update development tools with security fixes.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
