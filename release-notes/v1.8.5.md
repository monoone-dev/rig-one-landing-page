# RigOne 1.8.5 — Auto hands over finished work

*Released on 2026-10-23.*

This update lets Auto hand over finished work instead of looping on unrelated failures.

- A task whose own checks and verifier pass is delivered, even when an unrelated test elsewhere in the repository is red.
- Work saved before a failure is recovered, so a new attempt does not start from zero.
- Every repair is checked again before Auto moves on, and a reused check result names the run it came from.
- Fewer full gates run while a goal is in progress.
- The Rust build lock is released before tests run, so other runs wait less.
- Work that could not be measured at all stays "not verified" instead of passing or failing.
- The Lead gives a time estimate only once it has at least three earlier timings to go on.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
