# RigOne 1.8.6 — Remote redesigned for phones and tablets

*Released on 2026-10-23.*

This update brings the redesigned Remote for phones and tablets, and makes Auto remember and deliver more reliably.

- Remote on the phone and tablet has a new look built on SurfaceOne: a new chat layout, a project picker, drafts that survive a reload, and clearer activity and status views. Texts are translated into all 8 languages.
- A short loss of connection keeps the Remote session and screen, and answers sent while the phone was away still arrive.
- Stop ends active Auto work right away, and checking which GitHub account made each commit is much faster and no longer blames commits fetched at the same moment.
- The run view shows how much of your plan limits is used.
- Auto reuses what it already learned about your sources in earlier runs, and reflection stays with the agent app you chose.
- Large context reaches agents when they need it, skills arrive complete, and Planning gets the sources and project instructions you selected.
- Generated roles are checked the same way as workers, keep their identities, and Undo restores the setup you had before.
- Auto copies only the projects it needs, keeps unpublished branches and stashes when it cleans up, and shows the real outcome of each task after a restart.
- The full check runs web tests first and the Rust suite after them, so it fails faster and less often under load.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
