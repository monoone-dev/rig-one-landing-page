# RigOne 1.14.6 — Less waiting, and design reviews that survive a stop

*Released on 2026-11-04.*

Auto spends less time waiting, and a design review no longer gets lost when Auto stops.

- A design review card that closed when Auto stopped comes back by itself when the goal resumes.
- A part waiting for your design review says so and has a Show the design review button.
- Cards from a resumed goal reach the open window instead of a closed one.
- Ready checks go ahead while heavier work waits, and an approved check whose result did not change is reused later.
- An optional local compiler cache reuses Rust dependencies while each working folder stays separate. It is off by default and needs `sccache`.
- A missing prerequisite stops an expensive check early, and changed inputs no longer reuse an old result.
- Work across projects keeps pinned dependencies, and changes that are already in no longer create extra commits.
- Run history shows working time and waiting time without counting parallel work twice.

To update from 1.14.5, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
