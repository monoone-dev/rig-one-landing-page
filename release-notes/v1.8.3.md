# RigOne 1.8.3 — Agents that work the way they do in a terminal

*Released on 2026-10-22.*

This update lets agents work the way they would in a terminal and gets out of their way.

- Project setup is now a conversation with the Lead: say what you want and adjust the agents and skills afterwards.
- RigOne keeps its own agents and skills in `.rig-one` and no longer copies them into `.claude`, `.codex`, `.opencode` or `.agents`.
- Every agent runs with full access, like `claude` or `codex` in a terminal.
- Runs start even when steps share a folder or the disk is low; you get a warning instead of a refusal.
- Agents are no longer cut off by short time limits or after repeated tool errors.
- Steps start right away instead of waiting for free CPU or memory.
- The Auto Operator is gone, so its notices no longer interrupt the Lead.
- The Lead always starts the work you ask for, and you can click the options in a step's question.
- A role whose model is gone keeps working in Auto on the closest installed model, and Auto never picks Fable or Astra by itself.
- A check that already passed on the same files is not run again, so one full check runs at the end.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
