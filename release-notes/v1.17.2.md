# RigOne 1.17.2 — No stop after the author step

*Released on 2026-11-11.*

Auto runs no longer stop after the author step because of a leftover folder.

- A run no longer stops with "could not check who made the commits" when the repository still lists a temporary copy whose files were deleted; RigOne checks only real repositories.
- Auto no longer asks whether to add a test before it builds an interface: screenshots and the design review prove a screen.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
