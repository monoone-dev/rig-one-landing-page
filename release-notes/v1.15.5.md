# RigOne 1.15.5 — Simple organizations and plugin packages

*Released on 2026-11-08.*

Simple organizations and plugins.

- Organizations are simple: invite people by email, and they join. No device approvals and no keys to manage.
- Organization boards and projects are stored on the server as plain data, so every member sees the same state.
- Plugins: install a plugin package, give it settings, let it add agent tools and triggers, and keep it up to date. Plugins have their own page with ratings, and a Discord plugin is available.
- A plan opens as one workflow with a start and an end, each part in its own colour.
- Context is now called Materials and Knowledge is called Playbook.
- The feed stays still while the message box grows, and a few empty states and layouts are tidier.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
