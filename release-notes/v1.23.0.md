# RigOne 1.23.0 — Interactive plans and task windows

*Released on 2026-11-13.*

- Review an interactive HTML plan alongside the conversation before starting Auto. Select text, add comments and send feedback to the agent; then build the agreed plan in Auto or break it into tasks.
- Enable experimental task windows in Settings to keep up to ten tasks from different projects on one screen. Open tasks from their menus, and split, move, swap or resize panes with keyboard shortcuts.
- Plan previews appear before the first reply, keep comment counts in sync and support selecting text inside the app window.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
