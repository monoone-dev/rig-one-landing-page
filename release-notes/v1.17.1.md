# RigOne 1.17.1 — Organization boards for everyone, less disk for Auto

*Released on 2026-11-10.*

Everyone in an organization sees its boards, and Auto fails less and uses far less disk.

- Everyone in an organization opens every board, project and library item it owns, with no adding per board. People on an organization board lists everyone in the organization; invite and remove people in Settings › Organizations.
- Auto builds each project's Rust code in one shared build folder instead of one per copy, removes build output as soon as a run ends and no longer keeps copies of replaced attempts, so it waits less for disk space.
- Auto refuses plans whose checks or steps cannot work before the run starts, including gates that fail a run because a file outside the planned paths changed.
- Stopping a run counts as cancelled, closing RigOne pauses running goals so they resume later, and a resumed session no longer counts its cost twice.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
