# RigOne 1.9.1 — A refreshed run screen and the Linen theme

*Released on 2026-10-24.*

This update refreshes the run screen and makes Remote recover clearly when the server forgets your Mac.

- The model and an Auto switch now sit under the message field, and the model picker lays models side by side.
- Projects are set apart from actions in a full-width project menu, and the project overview shows repository facts and opens the project in your editor.
- A new Linen theme; both side panels and the terminal now follow each theme.
- When the Remote server no longer knows this Mac, RigOne stops retrying and tells you to turn Remote access off and on, then pair your devices again.
- Run copies no longer borrow outdated JavaScript dependencies from your project folder.
- Everything from 1.9.0 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
