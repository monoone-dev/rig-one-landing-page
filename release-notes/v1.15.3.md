# RigOne 1.15.3 — Boards stay small

*Released on 2026-11-08.*

Boards stay small and open instantly, however long their history.

- RigOne now keeps only the current state of each board on this computer instead of its whole history. A board that grew to hundreds of megabytes shrinks to a few hundred kilobytes and opens in about a millisecond.
- The first start after the update moves each existing board to the new form once and leaves the old file in place.
- Board content on this computer is stored as plain data, without encryption.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
