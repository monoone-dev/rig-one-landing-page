# RigOne 1.14.5 — Fewer repeated checks in Auto

*Released on 2026-11-03.*

Auto wastes less time on checks, and a Codex lead that cannot start says why at once.

- A check that already passed on the same code and command is reused instead of run again, also between a whole check and its parts.
- A failure caused by the check command itself, or a check that measured nothing, no longer sends the author back to repair the code.
- A test run that selects no tests after an earlier passing run is caught, and later parts stop once the command needs fixing.
- An Auto batch plan keeps one repository check, and a script check has to say what it covers.
- When a connection a Codex lead needs does not start, RigOne names that connection right away instead of waiting 30 seconds and saying Codex did not answer.
- The check card keeps the names of failed tests even when another part of the check printed no test output.

To update from 1.14.4, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
