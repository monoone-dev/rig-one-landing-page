# RigOne 1.11.0 — Projects side by side in tabs, and Auto goals that finish what they start

*Released on 2026-10-26.*

This update opens several projects side by side in tabs and makes long Auto goals finish what they start.

- Open several projects as tabs. Drag a tab onto another to join them in one split tab, onto the empty strip to take it out, or onto an edge to reorder. A colour tile tells projects apart, and ⌘⌥ shortcuts move between panes and tabs.
- In the Surface theme the window is drawn as islands on glass, with your macOS wallpaper showing through. A new Feather theme has light type, hairline edges and compact controls.
- Settings are split into Runs, Auto, Limits, Project, Connections, Agent apps and one page for each agent app, so each choice is easier to find.
- The new Storage page shows how much disk space RigOne uses, part by part, and Clean now removes what builds can make again. RigOne also cleans up sooner when the disk runs low.
- An Auto goal can wait for a condition and continues on its own when it is met, also after RigOne restarts. A saved goal resumes with one click, and its work is grouped by what needs you, what runs, what comes next and what is finished.
- A step whose agent waits for its own long background work, such as a build, is no longer stopped early.
- Checks count individual Vitest tests, show live diagnostics while they run, and keep completed work when required test evidence is missing.
- Run copies reuse installed dependencies, install their own when the lockfile differs, and no longer delete browsers another copy installed.
- Run workflow, Write cases and Build context turn into Stop in place while they work, and row actions are icon buttons that name themselves when you point at them.
- Remote on your phone is redesigned: Start, Projects, Conversations, Work, Planner, Boards, Needs you and Limits each have their own screen. You can start a new conversation or Auto goal, run selected Planner tasks after Face ID or Touch ID, and a message you are writing is kept if the connection drops.
- Sign-in keeps your session when the Keychain is slow to accept new credentials, and RigOne runs the newest OpenCode you have installed.
- Many smaller fixes to Auto, Remote, OpenCode and the run screen.
- Everything from 1.10.0 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
