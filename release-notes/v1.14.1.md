# RigOne 1.14.1 — An honest model picker, and a phone that takes every message

*Released on 2026-11-01.*

The picker tells the truth about a goal's Lead, the phone takes every message, and checks wait less for each other.

- In a goal's conversation the model and effort picker shows what the goal's Lead is set to, also after a restart. Sending a message no longer changes the level unless you changed the picker.
- The phone always takes your message. It leaves the field at once, later messages follow in order, and they go out when the Mac is back. If one cannot be delivered, its text returns to the field with the reason. The phone also says when the Lead is tidying up its memory.
- A long command shows its running time while it runs and its real duration when it ends.
- A check holds the Rust build lock only while it compiles, so other steps start sooner. Two checks of one project still take turns, so their tests do not disturb each other.
- A helper started by a run's step no longer appears as the step speaking.

To update from 1.14.0, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
