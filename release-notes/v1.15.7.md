# RigOne 1.15.7 — One board again

*Released on 2026-11-08.*

One board again.

- An old board finishes moving to the server, including tasks with long titles, and the old copy disappears so only one board is left.
- The Boards screen no longer says an update could not be read when everything is fine.
- Task titles can be up to 1000 characters.
- Items you shared to an organization say Shared by you, without Use or Download buttons.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.

## The package

`RigOne_1.15.7_aarch64.dmg` — macOS 13+, Apple Silicon.
