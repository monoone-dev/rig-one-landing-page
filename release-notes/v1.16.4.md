# RigOne 1.16.4 — Each conversation shows its own plan

*Released on 2026-11-09.*

Each conversation shows its own plan.

- A new conversation in a folder no longer shows the plan of an Auto goal that runs there from another conversation.
- Plan rows show each step by its own name, such as Security audit or Independent verification, instead of repeating the part title on every row.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.

## The package

`RigOne_1.16.4_aarch64.dmg` — macOS 13+, Apple Silicon.
