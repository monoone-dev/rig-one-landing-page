# RigOne 1.7.2 — A Lead that works like an agent in your terminal

*Released on 2026-10-19.*

## Auto

- **The Lead works like an agent in your terminal, inside a macOS sandbox.** It can run any
  command in its own workshop. The system itself stops it from touching your checkouts, other
  sessions, app data and secret stores, whatever command it tries.
- **It asks you only about what leaves your hands for good:** releases, tags, deployments and
  messages to people. Pushing branches, opening and merging pull requests and commenting go
  through on your pinned GitHub account without a question.
- **The Lead can change workflows and checks itself.** Every change is recorded in the goal's
  history with its diff, and a change that weakens a check is marked.
- **The Lead starts a fresh session after each finished process,** keeping the goal, its memory and
  its tools, so long goals stay fast and cheap.
- **The operator has a clear switch in Settings** (still off by default).
- **Setup proposes a UX/UI designer and a security reviewer** when your project has a user interface
  or handles accounts, keys or network access, and reviewers get a sensible default model.

## Disk and secrets

- **Old build files are cleaned up automatically,** and RigOne keeps at least 20 GB free, so shared
  build folders no longer fill the disk.
- **You can allow one specific credential file for steps** (for example a private package registry
  file) in Settings, with a clear warning.

## Remote

- **Long task titles on Boards wrap** on small phones with large text.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
