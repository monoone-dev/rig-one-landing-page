# RigOne 1.23.0 — Task windows

*Released on 2026-11-13.*

- Enable experimental task windows in Settings to keep up to ten tasks from different projects on one screen.
- Split task windows with keyboard shortcuts, move and swap them, and resize the layout to suit your work.
- Open a task in a task window directly from its menu.
- Small task windows keep their content readable.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
