# RigOne 1.13.5 — Analytics, a richer task screen and boards with kinds and costs

*Released on 2026-10-31.*

A Lead that answers you, a richer task screen and boards with kinds and costs.

- A Claude Lead that has an unanswered message from you can no longer start a long wait. It has to reply first.
- Text a Claude Lead writes between its actions now reaches you, on the desktop and the phone. It used to be hidden, so a Lead that had replied could look as if it ignored you.
- A message with only an image now reaches a working Lead straight away.
- The note that your message reached the Lead is a quiet, translated line instead of an English bubble that looked like a reply.
- New Analytics section shows what agents spent, and on which models and tasks.
- The task screen has icon run controls, task spend beside the composer, a plus menu, folding commands, and the model, effort and app beside new replies.
- Board items have a kind and can nest, cards show cost and tokens, and columns, sprints and templates work on shared boards.
- Settings shows each agent app's models, MCP servers, plugins and skills in tabs.

To update from 1.13.4, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
