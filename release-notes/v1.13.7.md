# RigOne 1.13.7 — Codex Leads answer you before a long wait

*Released on 2026-10-31.*

Codex Leads hold the same line as Claude Leads, and replies stay in step with your messages.

- A Codex Lead can no longer start a long wait while your message is unanswered. If Codex does not accept this check, the Lead still starts and is reminded instead.
- A message you send while a Claude Lead is working no longer makes the Lead's next reply end too early.
- A Lead in an Auto goal is not stopped as quiet while its own work is still running.
- An Auto Lead can find the skills saved on this Mac when it asks for them.

To update from 1.13.6, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
