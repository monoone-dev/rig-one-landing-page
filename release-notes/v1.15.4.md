# RigOne 1.15.4 — Auto stops less often

*Released on 2026-11-08.*

Auto keeps going in more of the situations where it used to stop and wait.

- Claude plan limits show again when Claude Code reports extra fields next to the usage windows.
- Auto switches to another agent when one runs out of usage headroom, instead of stalling.
- A step waits for its background work to finish before it hands in its result.
- Gaps you already accepted in a verification are honoured before delivery, and an older accepted gap can be renewed by your answer for the current result.
- A finished verification can be run again when its inputs change.
- A criterion that names a check before that check exists is refused up front.
- Saved author merges keep the main branch history, and copied build outputs no longer point back at the source folder.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
