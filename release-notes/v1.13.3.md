# RigOne 1.13.3 — Signed updates from inside the app

*Released on 2026-10-30.*

Signed updates from inside the app, honest Codex numbers, and leaner run storage.

- Settings → About can now check for, download and install RigOne updates. Every update is verified against RigOne's signing key before it installs, and active work holds the install and restart until it finishes.
- Codex token usage no longer counts the lead conversation twice when one of its helpers reports its own usage.
- Codex steps record the effort Codex actually confirms, and the step's evidence shows whether reading its settings back worked.
- Run storage compacts completed goals while keeping the history you can still recover, and an interrupted archive is no longer lost.
- You can set up a tool server (MCP) directly, imports of tool servers are bounded, and checking a local tool server no longer hands it your whole environment.

To update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`. Later versions arrive in the app, in Settings → About.
