# RigOne 1.2.6 — the Lead answers a message sent while it works

*Released on 2026-10-10.*

- **A message sent while the Lead works gets an answer.** It reached the Lead at once, but as a
  whole new-turn prompt: saved project context ("It is not a new user request"), the Auto
  instructions, the goal status and the list of sources, with your sentence as the last line.
  The Lead read it as material and carried on without replying. A message that joins a running
  turn (Codex and Claude) now carries only your text and asks the Lead to reply first, then
  continue.
- **A Claude Lead no longer looks busy forever.** Each message sent while a Claude Lead worked
  was counted as a new turn, but Claude adds it to the turn it is in and answers once. The extra
  turns never ended, so RigOne treated the Lead as still working. The message now joins the
  running turn, as it already did for Codex.
- **One failed turn no longer marks the whole conversation failed.** Diagnostics showed a working
  Lead as failed because an earlier turn had been interrupted; a turn that succeeds afterwards
  now returns the conversation to active.
- **Skip permissions says whether it is on.** The switch next to the agent picker now reads
  "Skip permissions: on" or "Skip permissions: off" instead of showing its state only in its
  border, so Auto steps no longer run fenced without you noticing.
- **A new turn names your message.** When a message starts a new turn with reference material,
  your text now stands under its own heading instead of below the list of sources.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
