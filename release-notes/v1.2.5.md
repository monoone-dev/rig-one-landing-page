# RigOne 1.2.5 — the Lead on Claude can start work again

*Released on 2026-10-10.*

- **The Lead on Claude can start processes.** Claude Code refused both of the Lead's process
  tools (`auto_start_process` and `auto_check_process`) because their schema held an empty
  `allOf`. A Lead on Claude could plan but never start a workflow. Codex accepted the schema, so
  only Claude Leads were affected (since 1.2.0).
- **Linked instruction files no longer stop a start.** A `CLAUDE.md` that is a link to
  `AGENTS.md` (a common layout) stopped every message with "Too many levels of symbolic links".
  A link inside the project is now read as the file it points to; a link that leaves the
  project, loops, or points to another link is skipped.
- **Plan limits are live for both vendors.** Codex limits showed "This Codex app cannot report
  plan limits" although Codex reports them; they now load. Claude Code limits are read live
  (no model turn, no cost) instead of from the last run's log, so they are no longer hours old.
- **Answers and actions look different.** In the stream, an agent's answer keeps its square,
  name and time. Commands, reads, edits and the end-of-turn summary are now one quiet monospace
  line under it, still naming who did them; a failed command stays red.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
