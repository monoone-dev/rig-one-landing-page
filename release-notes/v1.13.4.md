# RigOne 1.13.4 — Steps that wait for their own work, and repair loops that finish

*Released on 2026-10-30.*

Steps that wait for their own work, repair loops that finish, and faster runs.

- A step waiting for its own background work is no longer stopped after 30 minutes of quiet. Only the step's own time limit applies, and a truly idle agent is still stopped, with the real reason shown instead of an impossible number of minutes.
- A check that fails inside a repair loop now gets its next author try, instead of the run ending with "not from the same round".
- Agent steps followed by a check are told to run the tests for what they changed, so workflows repeat the slow suites less often.
- When a check cannot compare a failure with the code before the change, the base copy now installs its dependencies first, and the run and the Lead are told plainly when the comparison could not be made.
- The step screen is rebuilt in the new look.
- The phone connection falls back to bundled public certificates when the Mac's trust store cannot be read, so it no longer loses the relay on that error.
- Computer tools now show whether they are only configured or actually ready to use, and live Auto conversations are kept while old ones are cleaned up.

To update from 1.13.3, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
