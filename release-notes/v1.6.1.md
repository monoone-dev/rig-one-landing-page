# RigOne 1.6.1 — a Lead that keeps the goal moving and answers you

*Released on 2026-10-15.*

- **The Lead answers what you write.** If you reply in your own words to a question with options,
  the Lead now hears that you did not pick an option and answers your question before asking again.
  A message sent while an approval waits no longer cancels it: the card stays open and your message
  waits its turn. A decision that waits for you is repeated once an hour, at most three times.
  A message you send while the Lead is busy gets a reply before it carries on, and if the Lead is
  inside a long command the window says your message lands when that command ends.
- **The goal keeps moving.** A Lead that stops while its goal still has work and nothing is running
  starts again on its own, spaced out and at most three times without progress. Interrupt and "Stop
  the Lead" stop only the current turn; the new "Pause Auto" and "Resume" pause and resume the
  whole goal.
- **Work the Lead does itself is checked like any other.** A result the Lead records without a
  workflow shows as "Lead says done · not verified" until an independent review and the checks
  pass. A step that cannot go on now ends as blocked instead of as done.
- **Planner answers and questions read properly.** Planner answers show as text, and its questions
  land in Needs you. A quiet agent shows how long it has been thinking. Checks that build a lot can
  be marked as heavy work so they wait for the computer.
- **Runs clean up after themselves.** Step temporary folders and copied build output are removed
  when a run ends, and leftovers are swept at start. A run that ran out of time says so, a full disk
  is retried instead of failing the run, and the Lead learns when a usage limit resets.
- **Model gateways and OpenCode.** Run steps can go through a model gateway such as Kong AI
  Gateway, set once in Settings, so the gateway holds the keys. Through a gateway or an
  Anthropic-compatible endpoint, Claude Code and Codex agents can use other models typed by name.
  OpenCode joins Claude Code and Codex as a third agent app. A project setting can no longer send
  an agent's traffic to another address.
- **A branded installer.** The DMG opens in a styled install window with a shortcut to
  Applications.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
