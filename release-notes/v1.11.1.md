# RigOne 1.11.1 — Auto stops redoing finished work

*Released on 2026-10-27.*

This update stops Auto from redoing finished work and tells you where a goal's code really is.

- A check whose tests all passed is no longer sent back for rewriting just because its output lacked the expected text, and a test command that matched no tests is reported as a wrong command instead of failed code.
- A finished goal says when its code is not on the main branch yet, with the branch and how many commits wait there.
- Answers and blockers from workers reach the lead while a goal waits for you.
- Steps find npm and other Homebrew tools when RigOne was opened from the Dock or Finder.
- Remote: the Mac keeps its pairing after a temporary relay error, signing out ends phone pairings, the connection banner no longer flashes on short drops, and long conversation titles wrap to two lines on small screens.
- Setup that wrote nothing no longer says it was applied, an unavailable connection names the setting it needs, and diagnostics are copied with a verified copy.
- Codex usage is no longer counted twice after a resumed conversation, and preparing a step shows how many minutes it has taken.
- A run with many changed files no longer squeezes the plan's steps into empty bars; steps and the changes list each scroll in their own space.
- Everything from 1.11.0 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
