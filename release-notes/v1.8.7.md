# RigOne 1.8.7 — The Airy theme and agents you can create again

*Released on 2026-10-23.*

This update brings the new Airy theme, restores creating agents and regenerating the project setup, and makes Remote steadier on the phone.

- Airy, a lighter theme from SurfaceOne, is the new default. Every theme tile in Settings shows how it looks in the current mode.
- Every project on the Agents screen has a New agent button again.
- An applied project setup can be changed and generated again from the same dialog, and project generation is back in the side panel.
- Project setup and model repair no longer put roles on Fable or Astra. Model repair moves such roles to Opus or Sol.
- Remote keeps the view you were on after a refresh or a lock, and no longer reconnects in a loop after slow reads.
- Chat messages can carry more than four images.
- Answers in the terminal use the full width of the log, the start prompt is easier to read, and the DMG labels stay readable in light and dark mode.
- RigOne no longer repeats the same warning at every start for an old run whose project folder was renamed.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
