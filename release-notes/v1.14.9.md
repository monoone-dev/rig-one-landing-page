# RigOne 1.14.9 — Team projects, shared configuration and faster Auto

*Released on 2026-11-06.*

Auto gets faster from goal to merged work, no longer stalls behind a check that already ended, and team projects arrive.

- A check that stopped when an author's attempt ended gives this Mac's check slot back within seconds, instead of holding it until RigOne restarts and keeping every later check waiting.
- A new run of a Rust project starts from the last finished run's build output instead of compiling every crate again. Clean now and a low disk remove that kept output first.
- When Docker is installed but not answering, the run stops before the author starts and says that the computer, not the code, is at fault. A taken network port or a test process killed by the system also counts as a computer problem, so Auto retries once without asking for code changes.
- With more than one build allowed at once, checks compile in the same build lanes as agents. A second build starts only while the Mac has enough free memory, and the disk is checked for every build that starts compiling.
- Every reason a run waits for its folder is written to the log.
- In Auto, a reviewer that rejects the work sends it back to the same author in the same run, at most twice, instead of starting a new attempt.
- After three failed tries of one part, RigOne asks you what to do next. Tries stopped by a usage limit or by the computer do not count.
- A small interface task skips the separate design critic when a check and a look-only reviewer already judge it.
- Connect an open folder to a private or team project, manage organizations and invitations, and keep each computer's own folder mappings.
- Share versioned skills, agent roles, contexts, workflows and connection definitions, with explicit access and a review of each update.
- Boards follow project access. A task starts with a frozen configuration and the chosen agent role, and its questions and results return to the task thread.

To update from 1.14.8, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
