# RigOne 1.14.8 — One final check before delivery

*Released on 2026-11-06.*

Auto checks the finished goal once before delivery instead of repeating full test suites along the way.

- Auto implementation steps run focused checks. One final check per repository verifies the whole goal before delivery, and repairs happen in that same final check.
- Plans that repeat the full suite are refused, and Claude, Codex and OpenCode Auto sessions do not start known repository-wide test commands on their own.
- Delivery is refused when the final checks failed, when what they checked has changed, or when the branch moved after them.
- Rust builds share their disk reservation, and free space is checked again right before compiling.
- Python unittest results are recognized, and a package manager error is no longer read as a failed test.
- Auto repair loops no longer revisit the visual review without need, and stale waiting text is replaced when a workflow starts.
- A board read that is already stuck returns at once, and healthy reads running together share one time limit.

To update from 1.14.7, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
