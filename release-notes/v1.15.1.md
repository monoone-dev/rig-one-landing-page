# RigOne 1.15.1 — Boards open quickly again

*Released on 2026-11-08.*

Boards open quickly again, and starting a conversation from a board no longer hangs.

- Boards with a long history no longer freeze RigOne. RigOne remembers the board it last read and only reads it again when it changes, and it saves the board history in a much smaller form. The first start after the update converts the saved board once.
- Inviting a member, opening the board list and restoring conversations work again while a large board is syncing.
- Starting a conversation with a board selected starts the agent first and attaches the board afterwards, with a time limit, so a slow board can no longer hold the start.
- Closing a tab drops a start that was still waiting for it, and work is no longer sent to a closed tab.
- The sending sentence stays beside the new Cancel button while a message is on its way.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
