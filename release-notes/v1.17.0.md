# RigOne 1.17.0 — Sprints that are easier to plan

*Released on 2026-11-10.*

Sprints on Boards are easier to plan and track.

- A compact sprint header shows the sprint name with a switcher for active, planned and closed sprints, its dates, days left, progress and goal, with one main action and the rest under "…".
- The board no longer lists tasks outside the sprint above the columns; an empty sprint offers "Plan from backlog".
- The backlog groups tasks into collapsible sections for the active sprint, planned sprints and the backlog, and every task can be moved with "Move to…" or by dragging. Done tasks stay out of the backlog.
- Tasks an agent creates from a conversation get a short title, a structured description and acceptance criteria, with the original request quoted at the end.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
