# RigOne 1.13.2 — Honest Codex conversations, and boards a conversation can use

*Released on 2026-10-29.*

Codex conversations that tell the truth, and boards a conversation can use on its own.

- A Codex conversation no longer shows Done while Codex is still working after one of its helpers finishes.
- A conversation can create its own board task when you ask it to put the work on a board.
- Board replies from agents are threaded, subtask details open in a dialog, and people stay separate from the agents working for them.
- Auto checks that lint commit messages no longer fail on the commit RigOne makes before a check.
- A working folder saved for another run is refused once instead of at every start.
- The saved record of a Codex conversation shows which model and effort Codex actually used.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
