# RigOne 1.26.0 — Optional plugins and project boards

*Released on 2026-11-15.*

- Group boards into projects, with organization nesting, project icons and colors.
- Manage boards, remote access, imports, triggers, running apps, lessons, design review and analytics as plugins that can be removed in Settings.
- Run WebAssembly plugin packages through the plugin host.
- Try the experimental whiteboard to draw diagrams and hand them to materials. It is off by default and can be enabled in Settings.
- Enjoy clearer task descriptions, a distinct background for new tasks and accent-colored resize grips.

To update, open Settings → About. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
