# RigOne 1.16.1 — Sign out works again

*Released on 2026-11-09.*

Sign out works again.

- Signing out no longer says your Boards changes have not synced when everything is already on the server. Old changes left behind by the move of a board to the server are cleared, which also frees space on disk.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.

## The package

`RigOne_1.16.1_aarch64.dmg` — macOS 13+, Apple Silicon.
