# RigOne 1.19.1 — Fixes from a review of every screen

*Released on 2026-11-12.*

Fixes from a review of every RigOne screen and feature: shared skills land where you work, boards and goals close cleanly, and storage, triggers and setup say what they really do.

- A goal closes after its delivery step records a result, also when delivery only saved the checked tree again, instead of saying the integrated result changed.
- A folder that is still being tidied after start-up says so, and tidying no longer reads every goal once per old run.
- A shared skill from your organization is added to the project you have open, under its own name, with all its files. A skill somebody else wrote is not overwritten, and removing a skill removes the project's copy too.
- Shared items say where they landed, ask before adding a second copy, and the library refreshes after you share or update something.
- Tasks from organization boards start on this computer. A task linked to an Auto goal is no longer rewritten on every poll, edited comments stay visible, removed comments show their reason, and new tasks on a sprint board go into the active sprint.
- RigOne no longer says that boards and team data are encrypted. Starting over after a password reset keeps the organizations you own and shows the new recovery phrase once.
- An agent set to not reach the web no longer gets web tools, and Look only and Ask first say what they do. Codex starts read-only when a step only has look-up tools.
- Every setting keeps saving after you switch the build cache or the Save exceptions.
- Storage counts the whole build cache and each step's saved state, shows evidence outside runs and goals as its own part, and says at least how much Clean up now can free.
- A build that waits says whether it waits for another build, disk space or memory.
- Triggers read their key from `~/.rig-one/env` when the app has no such variable, ask Linear for up to 250 open issues, and name their source in the title.
- Lab keeps the whole new instructions when a proposed fix has headings, lets you pick the agent that writes cases and fixes, and lets you delete an eval set.
- Analytics counts the Lead's turns in Auto, keeps what a run spent after its folder is forgotten, and the spend chart covers the chosen period.
- Setup finds a role's skills where a run looks for them, treats packages inside one repository as one project, and stops flagging a Fable model you chose.
- Import keeps a memory file's whole content and says when an imported agent that edits files arrives as Look only.
- A task gets only the memory observations under the paths it works on, and the Playbook queue shows repeated and recent suggestions first, 20 at a time.
- Materials sets name their topics in the prompt and say when a Project setup set was built from files that have changed since.
- Settings → Connections lists your own tools, can delete a connection and shows a local server's command.
- A check step in a workflow can set its own time limit.
- Projects can be renamed or removed from the project menu.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
