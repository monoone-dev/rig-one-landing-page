# RigOne 1.11.8 — Quit stops every agent, and conversations take dropped files

*Released on 2026-10-28.*

Quitting RigOne now stops every agent it started, conversations take dropped files, and the window can be frosted glass.

- Drag images, files or folders onto a conversation: a drop area appears, then previews or badges that go out with your message.
- Each point of the project score has a run button that starts a fix task in the sidebar.
- Settings has a window transparency slider over a frosted macOS glass.
- Top bars share one look, with the same quiet icon buttons and tooltips everywhere.
- The sidebar shows Done, Stopped or Failed for a finished conversation, like the terminal, as a coloured badge.
- Cmd+Q and Quit in the menu ask first when steps are still running, then stop every agent and step before RigOne closes. Before, a normal quit could leave a Lead agent running in the background.
- If RigOne crashed, the next start stops any Lead agent the crash left running.
- Terminal view on the Surface skin in light mode is readable again.
- Links in your own and in agents' messages are readable on every skin, in light and dark.
- Agent names and avatar initials are dark enough to read on light backgrounds.
- Everything from 1.11.7 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
