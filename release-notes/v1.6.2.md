# RigOne 1.6.2 — tabs that come back, a Lead that runs workflows, apps that stay current

*Released on 2026-10-15.*

- **Your tabs come back.** After you quit and reopen RigOne, your tabs return in the same order
  with the same one active, with the names you gave them, in the workspace you last used. Each tab
  shows its earlier conversation again, loaded when you open it.
- **The Lead can run workflows.** With full access, the Auto Lead can use Claude Code workflows to
  run several agents at once. The window shows one line per workflow with how many agents are
  done, and opens to show each agent's model, state, length and result. Auto keeps going while a
  workflow is still making progress, and stopping the Lead stops every agent it started.
- **Agent apps stay up to date.** Settings → Agent apps shows the installed and newest version of
  Claude Code, Codex and OpenCode, with Update and Update all. RigOne updates an app only when no
  run or conversation is using it, can do so on its own when idle, and stops the apps from
  updating themselves in the middle of a run.
- **Clear notes on workflows Auto will not use.** The Workflows screen explains, in your language
  and by step name, why Auto will not use a workflow as a template, with a button that fixes it
  where that is possible.
- **One Rust build at a time, even under heavy load.** A waiting build could take the lock from a
  build that was only between two compile steps, so two builds ran together on a busy Mac. A build
  now gives up the lock only when it has really stopped.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
