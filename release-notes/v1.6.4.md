# RigOne 1.6.4 — Remote access no longer floods the account server

*Released on 2026-10-16.*

- **No more "Too many tries" after opening Settings.** RigOne asked the account server for your
  sign-in about twice a second while Settings or Boards were open, until the server refused every
  request from your network. Remote access settings now read only local state, Boards checks for
  changes every 15 seconds, and after the server asks RigOne to slow down it waits a minute.
- **A busy server never signs you out.** A refused, offline or unconfirmed account check keeps
  you signed in; only an ended sign-in signs you out.
- **Remote access says what is wrong.** The settings card shows the real reason, such as "Too many
  tries" or "Couldn't reach the server", instead of "RigOne could not save this action", and every
  lost relay connection is written to the log with its reason and the next retry time.
- **The relay link retries calmly.** Retries spread out over time and wait at least a minute after
  the server asks RigOne to slow down.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
