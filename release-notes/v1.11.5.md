# RigOne 1.11.5 — Auto picks the model and effort for each step

*Released on 2026-10-27.*

Auto now chooses the model and effort for every step to fit what that step has to do.

- A role's saved model and effort are only a starting point. For each step, Auto picks a model from every allowed one (Opus, Sonnet, Haiku, Astra, Sol, Terra or Luna) and states why it fits. It never picks Fable on its own.
- Each step records the model and effort it asked for next to the ones the agent app reported. When they differ, run history says so.
- An agent's effort is the only setting for how deeply it thinks, so its profile can no longer show a second level that contradicts it.
- Everything from 1.11.4 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
