One graph owns the work

RigOne is a native macOS control room for coding agents. Define an agent once, place it on a canvas, connect the steps, and run the graph against a project. Claude Code and Codex are first-class peers.

What it does

Visual workflows

Agent steps, local commands, checks, checkpoints, loops, conditional paths and retries — saved as a graph you can run again.

Real parallel execution

Independent branches overlap in time instead of taking turns behind a single worker. Order comes from the graph, never from the engine.

A run screen you can read

The plan on the left, what every agent said on the right, and the question that stopped the run pinned where you will answer it.

Reusable agents

Vendor, model, reasoning depth, timeout, file access, tools, connections and skills — chosen once per role and reused everywhere.

Project-scoped knowledge

Curate instructions and notes on disk, then see which context a run actually used.

Evidence that outlives the terminal

Run receipts, attachments, handoffs, death proofs and a diagnostic bundle stay available after the output is gone.

Built to fail honestly

RigOne treats orchestration failures as product failures, not terminal noise.

  • Overlapping write scopes are refused before the first process starts.
  • Cancellation terminates the whole process group and then proves it is dead.
  • Timeouts travel through that same supervised shutdown path.
  • Prompts and secrets go through stdin, never command-line arguments.
  • Child environments are rebuilt from an explicit allowlist.
  • Unknown vendor events are recorded and ignored instead of crashing the run.
  • A green exit code without proof that tests ran is not accepted as a green check.
  • Files are the truth; the database stays a rebuildable index.
