# RigOne 1.22.1 — Remote fixes

*Released on 2026-11-13.*

- Auto confirmations are saved reliably, so your decision remains available when work continues.
- Remote checks the result of an action from your phone without sending it again when the response is delayed.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
