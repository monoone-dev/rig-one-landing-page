# RigOne 1.6.0 — nine languages, sprints, and one Rust build at a time

*Released on 2026-10-14.*

- **RigOne speaks your language.** The interface is now in English, Polish, German, Spanish,
  French, Italian, Portuguese, Chinese and Japanese. It follows the system language, and you can
  choose another in Settings → Appearance. What agents and the engine write in a run stays in
  English.
- **Sprints on boards.** A board can switch between Kanban and Sprints, with planned, running and
  closed sprints. Board settings open over the board and set the columns, their colours and
  order, and whether finished sprint tasks are archived or deleted after a number of days.
  Dragging a task card onto another column works again.
- **One Rust build at a time, for real.** In 1.5.0 the limit of one Rust build at a time did not
  reach agents whose commands start a login shell, so several builds could run together and slow
  the Mac down. Every build started by RigOne now waits for the one before it, whichever shell
  started it, while tests, running apps and other work carry on side by side.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
