# RigOne 1.25.0 — Scheduled workflows and plan canvas

*Released on 2026-11-14.*

- Run saved workflows on a schedule, including every five hours, without an external connector or API key. Scheduled checks run while RigOne is open.
- Review plans on a canvas with anchored comments, zoom and navigation tools.
- Read plan steps as one continuous list with badges beside the text.
- Keep and discard controls use matching icons, with clearer Knowledge health notes.

To update, open Settings → About. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
