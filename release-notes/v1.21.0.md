# RigOne 1.21.0 — Remote says what it knows

*Released on 2026-11-12.*

Remote on your phone now says what it knows: whether a page is up to date and how far each action got. On the Mac, a review pass across the whole app makes messages clearer and fixes rough edges in boards, workflows, triggers and storage.

- Remote shows whether the page you are looking at is up to date, being updated or possibly out of date, and each action you send says where it stands: saved on the phone, waiting for your Mac, accepted, refused or unknown. Conversations and the inbox now sync to the phone with confirmation, commands are more reliable and the connection stays up longer.
- When no agent app is ready, the message points you to Agent apps instead of only saying to install one, and Retry is an outline button.
- Settings → Storage counts run records, boards and remote access data in the total, and failed packing attempts count against the budget.
- In workflows you can delete an arrow, the canvas fits again after you resize the window, and check parts have separate edit actions.
- A disabled trigger shows how many issues are waiting to start and lets you discard them. Linear triggers read every page of issues.
- Boards group agent notifications by task, keep a reply until its delivery is confirmed, take spending from conversation receipts and keep card titles to two lines.
- A pinned decision appears once instead of also in the transcript. Auto explains provider limits and outside-the-code reasons in Polish and the other app languages.
- Agent options show translated warnings before you save, and generated agent apps are checked before use.
- Importing a project explains which personal connections it skipped, and the Lead sees the tools available from installed packages.
- Memory explains the note budget and collapses health details; older Lead memory stays with its project. Skills refuse maintenance from stale sources.
- A build that waits for a lock it already holds through a parent process no longer announces a wait.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
