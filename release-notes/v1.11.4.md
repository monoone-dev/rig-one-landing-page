# RigOne 1.11.4 — Honest checks in npm workspaces

*Released on 2026-10-27.*

This update keeps checks honest in projects that use npm workspaces.

- A run's copy of a project whose npm workspace installs its own packages now gets its own dependencies, so checks no longer fail at a missing package and a check of the base no longer looks red for the wrong reason.
- Everything from 1.11.3 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
