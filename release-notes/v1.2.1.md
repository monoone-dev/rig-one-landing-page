# RigOne 1.2.1 — opens at once

*Released on 2026-10-08.*

RigOne 1.2.0 could take two minutes to show its window, and to macOS it looked frozen. Before the
window appeared, RigOne tidied what the last window had left in each of your project folders. In a
large project that meant re-checking every file of every past run's starting snapshot, and it did
this on every launch, even when nothing was left to recover.

- **The window opens straight away.** RigOne tidies your folders in the background now. A command
  that touches a folder waits until that folder is tidied, so a run you start is never mistaken for
  one the last window left behind.
- **Finished runs are not re-checked.** RigOne checks a run's snapshot only when it actually has a
  result to bring back. On our largest project, tidying went from almost two minutes to about two
  seconds.
- **A result that cannot be brought back is not retried on every launch.** If a cause will not go
  away by itself, such as a folder that has become a link, RigOne notes it once and leaves the run's
  folders as they are. If that cause changes, or RigOne is updated, it tries again. A passing
  problem, such as a busy file or a missing permission, is retried on the next launch.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
