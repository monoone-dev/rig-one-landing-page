# RigOne 1.14.3 — Auto stops looping on the same failure

*Released on 2026-11-02.*

Auto stops looping on the same failure, keeps tests it already passed, and answers you after it tidies its memory.

- A test that passed on the same code and command does not run again in a later try, after a restart or in a new working copy. The result says which try passed it.
- Auto refuses to start the same failed try again on unchanged code until the code or the test changes, or the lead names a cause.
- A full disk, a stopped Docker or a test database that will not start is reported as a computer problem, not as a fault in the code.
- A new Rust process waits with a plain reason when the disk does not have room for it.
- A message you send while the lead tidies its memory gets its own turn and a reply.
- A stop card in a goal says what happens next and offers "Stop and carry on", so you do not have to write another message.
- A process you stopped starts again after your next message without an extra step.
- The conversation is quieter: no raw records, no false warning after moving to a saved commit, preparation folded into one translated line, and a connection problem said once per run.

To update from 1.14.2, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
