# RigOne 1.16.0 — Live design review

*Released on 2026-11-09.*

Design mode: review a design live, and approve everything once.

- When a part with interface changes is ready, RigOne starts the app itself and Needs you shows Design review. Open it, pick an element or write a note, and the same agent changes it within moments while you watch. Approve design ends that design for good; checks run on the approved version without asking you again.
- Write "approve everything" (or "zatwierdzam wszystko") in a goal chat and nothing in that goal waits for your approval again, also after a restart. The plan header shows it with Undo.

To update, open Settings → About and install it. From a version without the in-app update, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
