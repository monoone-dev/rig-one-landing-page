# RigOne 1.5.0 — a new look and a steadier Auto

*Released on 2026-10-13.*

- **A new look.** The whole interface now uses the same design system as IndexOne: the same
  buttons, fields, cards, menus and dialogs, with tidier layouts. Pick your look in Settings →
  Appearance: Minimalist (the default) or Studio, in light, dark or following the system. RigOne
  also has a new icon.
- **Settings as a window.** Settings opens as its own window with categories, including new
  Appearance and About sections (your version and a link to the latest release).
- **Faster run screen.** A long conversation keeps only its newest lines on screen and brings
  earlier ones back as you scroll up, also from the saved files. A running workflow no longer
  redraws the whole screen on every batch of lines.
- **More work at once.** Rust builds now wait for each other on their own, so only one runs at a
  time on your Mac, while reviews, checks and other steps run side by side instead of queuing for
  a single slot. Goals that wait for the same folder take turns in the order they asked.
- **Auto keeps going when the provider is busy.** When a model is at capacity or overloaded, the
  step waits and continues the same conversation, and the window says when it tries again. A
  usage-limit wait now shows its reset time.
- **Needs you, in one place.** A decision shows once, in Needs you, and the panel stays with the
  tab it belongs to and closes after the last answer. A question the Lead asks in its reply now
  gets its own card. Any question card can be dismissed. A checkpoint that points at a mockup,
  screenshots or a review shows them, with buttons to open them.
- **Stop what you mean.** Stop the Lead stops only the Lead, while its workflows keep running.
  Stop Auto and its workflows says how many workflows it will end and asks first.
- **Fewer false failures.**
  - A verified result is no longer refused because of ignore rules an earlier step added.
  - A copy whose dependencies match the project borrows them, so JavaScript checks can run.
  - A check that needs a clean tree passes in a task that RigOne commits itself.
  - A commit made on GitHub in a step's starting point no longer stops the step.
  - Notes for the Lead are saved even when a step fails on its scope.
- **Steadier goals.**
  - Workers receive the text of the sources their process names.
  - After RigOne restarts, goals whose workflow was cut off say so instead of looking busy.
  - A published result carries only its own change.
  - Recording a result after an earlier one was squash-merged no longer conflicts.
- **Smaller fixes.**
  - Task-list workflows are laid out top to bottom.
  - Project setup leaves RigOne's own files out of its evidence.
  - Steps get a temporary folder short enough for sockets.
  - Diagnostics name steps cut off by closing RigOne and steps stopped by a busy provider.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
