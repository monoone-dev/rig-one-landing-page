# RigOne 1.1.0 — Loadout is now RigOne

*Released on 2026-10-04.*

The application you have been running as **Loadout** is now **RigOne**, and it lives with
IndexOne under [MonoOne](https://github.com/monoone-dev). The name, the icon and the home of the
source changed. Nothing about how it runs your workflows did.

**Your library comes with you.** The first launch moves `~/.loadout` to `~/.rig-one` — agents,
workflows, context sets, settings, prices and the whole run history, together with the index and
its write-ahead log. The first time you open a project folder, that folder's `.loadout/` becomes
`.rig-one/` the same way. If both names are already there — because you kept an older build and
ran it as well — nothing is touched and the log says so, rather than one library overwriting the
other.

**macOS sees a new application.** The bundle identifier moved from `com.loadout.desktop` to
`com.monoone.rigone`, so the system treats RigOne as an app it has never met:

- Permissions start over. The first run will ask again for the folders you work in, for sending
  events to other applications, and for the microphone if a workflow drives an app that records.
- The old **Loadout.app** stays in `/Applications` as a separate app. Delete it once you are
  satisfied RigOne has your library; it still points at the data RigOne has already moved.
- Releases before this one cannot update into this one. Download the DMG and install it beside
  the old app, then remove the old app by hand.

**A new mark.** A silver ribbon folded twice on a dark tile — the same construction IndexOne
uses, so the two look like what they are. The logotype is `RigOne`, one word.

**Where things are now.** Releases, release notes and the issue tracker:
[`monoone-dev/rig-one-landing-page`](https://github.com/monoone-dev/rig-one-landing-page/releases).
Release notes before this one keep the old name, and so do the files they name: those DMGs exist,
under those names, with those checksums, and a renamed sentence would point at nothing.

To update, download the macOS Apple Silicon DMG and install it, then delete the old
**Loadout.app** once your library has arrived.
