# RigOne 1.12.0 — A new look for the main pages, and checks that judge failures fairly

*Released on 2026-10-29.*

A new look for the start screen and the main pages, checks that judge flaky and old failures fairly, and a clean-up that finally frees disk space.

- The start screen keeps only the question and the field. The model popover is one panel that always fits the window, the same on the new task screen and in a conversation.
- The workflow editor has a page-style header, one settings row and a graph laid out top to bottom with no overlapping steps.
- Overview is split into tabs, with a summary of figures and a list of what needs attention. Knowledge gets a health check that flags knowledge that is too big, out of date or unused.
- Agents open on a list. An agent is read-only until you press Edit.
- Plan limits show only the apps that are on and signed in, as rows with logos and details on hover, pinned to the bottom of the side panel.
- The side panel shows the GitHub account you work with, and Settings has a GitHub page with the account's details and permissions.
- A check that passed once is reused across workflows when it proved the same thing on the same code, instead of running again.
- A check whose only failures are flaky tests outside the change now passes with a warning that names the tests to remove. A failure inside the change, or one that is also red without it, still fails.
- When a check is red, RigOne re-runs it on the code without the change, with the same dependencies, to tell old failures from new ones.
- A red check now says first which tests failed or what stopped it, instead of "Test runner not recognised" or only listing the required tests that never ran.
- The Lead's plan is refused before the run when a check could never confirm the tests it must confirm.
- A check waiting for another Rust build no longer blocks the other checks, and installing dependencies never waits behind a heavy check.
- A Lead waiting on a long command hears your message straight away, on Claude and on Codex. The command keeps running.
- A request typed while a project starts is no longer lost.
- When the disk is low, RigOne removes whole copies of runs that ended more than three days ago and have nothing unsaved, oldest first. Settings → Storage shows how much the last clean-up freed.
- Claude steps record the effort they ran with, like Codex steps.
- Polish texts about GitHub accounts use the same voice as the rest of the app.
- Everything from 1.11.8 is included.

To update, download the macOS Apple Silicon DMG and replace RigOne in `/Applications`.
