# RigOne 1.14.7 — Auto stops early on unfinished work

*Released on 2026-11-04.*

Auto stops early when an author cannot finish, instead of running expensive checks on unfinished work.

- When an author reports unfinished work, a missing scope or a missing test setup, Auto stops before the expensive checks, keeps the saved work and tells the Lead what blocks it.
- A test command that finds no tests is told apart from a command that is wrong, and a quick check that cannot run is no longer repeated.
- A design review left for later is kept, and the Lead hears the current decision even when an older failed attempt finishes late.
- An older result can be settled by a verified replacement without replaying old changes or losing its acceptance criteria.
- Separate working copies may change the same files at the same time, RigOne names what holds disk space, and waiting work starts as soon as that space is free.

To update from 1.14.6, open Settings → About and install it. From an older version, download the macOS Apple Silicon DMG once and replace RigOne in `/Applications`.
